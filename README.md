# Autowerkstatt Website

Rohversion für eine moderne Website einer Ein-Mann-Autowerkstatt.

## Dateien
- `index.html` – Seitenaufbau und Inhalte
- `style.css` – Design und responsive Darstellung
- `script.js` – mobiles Menü und Demo-Formular

## Noch einzutragen
Werkstattname, Anschrift, Telefon, E-Mail, Leistungen, Öffnungszeiten, Logo, Fotos, Aktionen und der echte Formular-Endpunkt.

**Hinweis:** Das Terminformular versendet in dieser Rohversion noch keine Daten.
